# Demo: Semantic IR Diff Dashboard

This file shows a captured example dashboard generated by the `semantic-ir-diff` CLI when comparing two small LLVM IR files.

## Command run

```powershell
python -m semantic_ir_diff.cli tmp_dashboard/old.ll tmp_dashboard/new.ll --old-ir --new-ir --report-detail all
```

## Dashboard output

- Removed functions: 1
- Changed functions: 1

- `bar`

Function changed: `foo`
